# The Portrait Lab Releases

Download the latest version of The Portrait Lab from the [Releases](https://github.com/hurd300403/theportraitlab-releases/releases) page.

## About
The Portrait Lab is an AI-powered portrait editing tool for photographers.

## Update feed

GitHub Pages publishes `appcast.xml` and the root-level HTML release notes.
Downloadable apps and delta updates are served from GitHub Release assets; the
matching archives under `updates/` are retained only for future delta generation
and are excluded from the Pages artifact by `_config.yml`.

If a Pages deployment is canceled, do not retry the canceled commit directly:
Pages keys deployments by commit SHA and keeps that SHA in the canceled state.
Resolve the original lock, make a new documentation or feed commit, and deploy
the new SHA.
