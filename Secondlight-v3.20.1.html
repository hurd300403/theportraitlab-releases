Version 3.20.1


Secondlight 3.20.1 improves layer review and batch prompt editing.

- Selecting a layer gives keyboard control back to the editor, so arrow navigation and label shortcuts work immediately.
- Single-click a thumbnail to select it. Double-click to open color and star quick actions.
- Press the same color shortcut (A/S/D/F/G/H) or star shortcut (1/2/3) again to remove that label.
- Double-click a batch prompt to edit it directly. Return saves and Escape cancels.
