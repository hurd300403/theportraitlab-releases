Version 3.18

Secondlight 3.18 improves batch editing, preserves color labels in Generation History, and makes filtered layer editing more predictable.

• Batch instructions now have clear Save and Cancel controls. Return saves your changes; Escape cancels them.
• Unpinned Batch Processing panels close reliably when you click elsewhere. Pinned panels stay open.
• Color labels on generated layers now save automatically to their matching History entries, independently of saving the photo session. History displays those labels and restores them when you insert or drag an image back into the editor.
• Undo and Redo update the saved History label, too. If a History save fails, a message and Retry Save button help you recover.
• Select and reorder matching layers within the same group while a color filter is active. Selected layers move together, hidden layers keep their positions, and Undo and Redo restore the layer order reliably.
• Clearing or changing a label keeps the active color filter in place, even when no matches remain. Undo restores the label and brings the matching layer back.
