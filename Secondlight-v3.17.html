Version 3.17

Secondlight 3.17 improves undo and redo controls and makes switching between photo sessions smoother.

• Edit → Undo and Edit → Redo now use the active photo’s editing history.
• Restore removed or changed layer color labels from the Edit menu or keyboard shortcuts, including labels changed through thumbnail holds and layer menus.
• Text fields retain their own undo history, and layer label changes stay with the correct photo session.
• Switching photo tabs now closes the previous photo’s export panels and returns to the destination photo’s layers.
