Version 3.11.1


Secondlight 3.11.1 fixes cross-session render mix-ups and the apparent few-pixel layer shift caused by a source image from another session being reused.

Batch Processing now safely recovers slow or interrupted renders without submitting duplicate work or charging twice, releases stalled queue slots so later layers can continue, and retries genuine provider failures. Session tabs show actual rendered-layer counts instead of warning exclamation marks.

This release also includes the 3.11 Batch Activity panel (collapsed by default) and completed-session layer reliability improvements.
