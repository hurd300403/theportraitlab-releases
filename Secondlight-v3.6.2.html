Version 3.6.2

Secondlight 3.6.2 repairs the updater and includes the stability improvements from 3.6.1.

- Repairs the in-app updater so future updates install normally.
- Keeps Batch Processing queues between app launches and computer restarts.
- Fixes crashes when dragging Batch Processing and cubby tabs.
- Fixes toolbar status-pill sizing and overlap.
- Keeps batch export work off the main thread to prevent hangs.
- If Secondlight 3.6 or 3.6.1 shows an update error, download and install 3.6.2 manually once from secondlight.app. Future updates will work in-app.
