Version 3.11.2

Secondlight 3.11.2 removes the blocking frozen-batch state. Finished runs now return immediately to normal editable rows and Run controls while retaining the actual render count.

Batch scope is now simply This session or All sessions. One-click row duplication is restored, and Duplicate and Copy Instruction remain safely available while work is queued or rendering.

This release also improves session isolation, retry handling, slow-render recovery, layer reliability, and rendered-layer alignment.
