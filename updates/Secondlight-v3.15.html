Version 3.15

Secondlight 3.15 runs all checked Batch Processing prompts across every prompt tab in one combined batch. Prompt counts, badges, and credit estimates include the full selection automatically—no extra tab-scope setting is needed.

Choose All sessions to apply that combined selection to each eligible open photo session. Each session keeps its own captured Base Image, settings, progress, and results. Submitted prompts keep their source-tab labels, and copies added for a later run remain visible under the right tab.

Tab selection and clearing controls now state exactly which tab they affect. Drag-and-drop between prompt tabs remains available.
