Version 3.8.1


Secondlight 3.8 significantly upgrades Auto-Align for layered photo workflows. It now automatically corrects position, rotation, scale, affine distortion, and perspective while preserving existing layer placement. Multi-image sequences align more reliably through overlapping neighbors, uncertain matches remain unchanged, and a complete multi-layer alignment can be undone in one step.

This update also fixes an issue where restored sessions, especially with expanded Liquify controls, could cause the canvas and interface to extend vertically beyond the window. Tool controls now stay within the window and scroll when needed.
