Version 3.11


Secondlight 3.11 keeps Batch Processing controls accessible and makes generated layers substantially more reliable across completed and concurrent sessions.

- Batch Activity now starts collapsed, so long queues no longer push batch controls off screen.
- Generated layers remain available and toggle correctly after batch sessions finish.
- Session image caches are isolated across app and test processes to prevent one process from removing another session's pixels.
- Legacy session-cache storage can be reviewed and cleared explicitly from Storage settings after older Secondlight builds are closed.
