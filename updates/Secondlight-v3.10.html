Version 3.10

Secondlight 3.10 makes Batch Processing flexible and reliably session-aware.

- Organize reusable batch instructions into prompt sets and drag rows into the order you want.
- Queue work for individual open sessions with independent progress and cancellation.
- Each queued run keeps its captured session, prompt set, row order, and Base Image while you work elsewhere.
- Clearer row status makes it easier to see what is ready, rendering, complete, or failed.
